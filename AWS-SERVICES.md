# Current AWS Service Mapping

**EC2**- Medium size instance that runs the FastAPI backend
**RDS**- Small size relational database database with fast CPU
**Cognito**- User auth & management. Should have multiple sign-in methods
**S3**- Stores compiled React frontends
**CloudFront**- Delivers frontend over CDN
**Route 53**- DNS management for domain
**ACM**- Public TLS certificates for HTTPS
**VPC**- Network isolation and subnets and whatnot
