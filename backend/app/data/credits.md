# Credits

Versions are the ones locked for this repo. Licenses are the ones those packages publish.

## Frontend contract libraries

- [openapi-typescript](https://github.com/openapi-ts/openapi-typescript) 7.13.0, MIT. Generates `frontend/src/api/schema.ts` from the exported OpenAPI document. Do not edit that file by hand.
- [openapi-fetch](https://github.com/openapi-ts/openapi-fetch) 0.17.0, MIT. The shared typed HTTP client in `frontend/src/api/client.ts`.

The Bun lockfile is `frontend/bun.lock`. The npm lockfile is `frontend/package-lock.json`.

Other third-party tools, data, and libraries stay listed in `PRD.md` section 19 until the README credits section is written.
