# Supplied source fixtures

These files preserve the event-provided patient seed table and clinician role examples used by the dataset audit. Keep them as source material; import or normalized cases should retain a reference to the source file and row or JSON path.

The profile examples are scenarios, not real patient records. They are not labeled examples of student skill or learning. The clinician profiles came from the Connected Care challenge and are included to support cross-challenge role analysis.

The external dataset links are recorded in `backend_kelsch/app/data/dataset_manifest.json`. Their contents are not copied into this repository. Confirm upstream license and provenance before downloading or redistributing them.
